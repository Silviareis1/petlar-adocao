## 💜 Sobre o projeto

A **PetLar** é uma landing page criada como atividade prática da **Formação Desenvolvedor Full Stack Júnior 2026 — +praTI / Codifica**. O projeto apresenta uma iniciativa fictícia de adoção responsável, com uma interface acolhedora, responsiva e interativa.

> **Aviso:** este é um **projeto educacional e demonstrativo**. Os animais apresentados são exemplos fictícios, e o formulário **não envia mensagens nem solicitações reais de adoção**.

## ✨ Funcionalidades

- 🏠 Cabeçalho com navegação por âncoras e menu adaptado a telas menores.
- 🐶 Seção principal com imagem de destaque e chamada para ação.
- 🐱 Cards ilustrativos dos animais Mimi, Bento e Luna.
- 📱 Layout responsivo para desktop, tablet e celular.
- ✉️ Formulário de contato com campos obrigatórios, validação básica e mensagem de agradecimento via JavaScript.
- 💡 Seção **“Você sabia?”** com curiosidades sobre gatos obtidas por uma API pública.
- 🛡️ Tratamento de erros na consulta à API.
- ♿ Recursos de acessibilidade, como estrutura semântica, rótulos dos campos, textos alternativos e indicação de foco por teclado.
- 🎨 Identidade visual com lavanda, verde-menta, creme, pêssego e grafite.

## 🔌 Consumo de API

A seção **“Você sabia?”** utiliza a [Cat Facts API](https://catfact.ninja/) para obter curiosidades sobre gatos por meio de `fetch()`. As respostas são fornecidas pela API em **inglês**. Caso a consulta falhe, o site apresenta uma mensagem amigável ao visitante.

## 🚀 Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/Silviareis1/petlar-adocao.git
   ```

2. Abra a pasta `petlar-adocao` no **Visual Studio Code**.
3. Abra o `index.html` com **Live Server** ou diretamente no navegador.
4. Mantenha a conexão com a internet para carregar a biblioteca de ícones e consultar a API.
